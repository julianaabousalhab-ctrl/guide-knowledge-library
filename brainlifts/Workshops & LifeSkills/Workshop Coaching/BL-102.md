# A "Behind" Flag Is Not an Intervention — Record the Barrier and the Booked Response

## Pattern

When a checkpoint marks a student Behind on the workshop's life skill, the strong Guide practice writes two things next to the flag, at the moment of flagging:

1. **The specific barrier** — the named stuck point or skill gap ("grip strength," "filler words and confidence," "gaps in writing practice — too much distance between assignments to build on one another"), not a restatement of the status.
2. **The booked response** — a concrete intervention with a time, owner, or mechanism ("extra coaching session scheduled during Q-Break this Wednesday," "1:1 calls with the Pro Tools producer will be booked," "flashcards for home use with the spelling techniques that work uniquely for her"), not an intention to "keep working with" the student.

The mechanism: the checkpoint system (BL-096's architecture, applied to workshops) reliably *detects* Behind students — but detection only pays when the flag converts into a diagnosis and a scheduled response. A status cell with no note postpones the intervention decision to whenever someone next remembers the student, which is the attention-based failure mode the tracker exists to remove.

Related: BL-096 governs the detection side — fixed cadence, numeric flags, timed review. This pattern governs the record's content once the flag fires. BL-041's barrier taxonomy (strategy / instructional fit / system) is the diagnostic lens for step 1.

## Anti-Pattern

The anti-pattern is flagging without responding: the status cell says Behind and nothing else.

*1- The majority case, measured*

Of 1,370 Behind flags recorded across the S3–S5 trackers, 816 (60%) carry no coaching note at all — the detection system fired and the response record is empty.

Source artifact: Workshop Skill Trackers SY25-26 — checkpoint status vs coaching-feedback columns, corpus-wide count

*2- The generic-note variant*

A small set of notes restate intent without a barrier or a booking: "coaching through fear"; "Guides are continuing to coach [student] on setting ambitious goals and challenging himself…" — statements that could be written about any student in any workshop, deferring the actual decision.

Source artifact:[Workshop Skill Tracker](https://docs.google.com/spreadsheets/d/1S-FiD2L3ziI8c8q97QwKJqFayLBf2_gaOQ0rf2KehGI/edit?usp=sharing)

## Reusable Coaching Move

When you mark a student Behind, finish the row before moving on:

1. **Barrier:** "What specifically is blocking this student?" — name it in the student's terms (skill component, confidence, missing prerequisite, system issue). Use BL-041's three-way test if unsure.
2. **Booking:** "What will happen, and when?" — an intervention with a time and an owner ("Q-Break Wednesday," "1:1 during Friday's session," "materials going home Monday").
3. **The test:** could another Guide read the row cold and run the intervention? If not, the note isn't finished.

## Confidence: Medium — 548 substantive instances across ~20 campuses with a measured 60% anti-pattern base rate, but the corpus does not link note quality to T2P outcomes, so the effect claim rests on the mechanism rather than measured results.
