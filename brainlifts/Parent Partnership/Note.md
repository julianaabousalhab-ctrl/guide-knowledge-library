# Node 8.1 — Writing Guide Comments

## In

- **BL-058:** Write in Reality → Lever → Next Step order.
- **BL-059:** Use evidence unique to the student — quotes, interests, behaviors, and concrete moments.
- **BL-060:** Take Guide ownership of the gap — name what the Guide has not yet delivered or unlocked.
- **BL-061:** Prioritize one high-leverage growth area.

These were included because they describe distinct writing behaviors supported across multiple Guide Comments.

## Out

- **Grammar, spelling, and copyediting issues** — out of scope for this node.
- **Comment length as a standalone BrainLift** — treated as part of prioritization rather than a separate pattern.
- **Repeating every score or subject shown elsewhere in the report** — excluded.
- **General positivity without evidence** — excluded.
- **Parent-response or parent-conversation practices** — parent interaction belongs under 8.2.

## Ambiguous

- Some comments used strong evidence but were too long.
- Some comments showed Guide ownership but lacked a concrete next step.
- Some comments contained several useful strategies tied to one subject.
- These were classified by the primary behavior being evaluated. A comment could support one BrainLift while serving as an anti-pattern for another.

# Node 8.2 — Giving Parent Feedback

## In

- **BL-062:** Describe observable behavior, not character, motive, or fixed traits.
- **BL-063:** Explain relevant context, then state the Guide's action.
- **BL-079:** Deliver the consequence with the stakes, the plan, and evidence-based belief in one message.

These were included because the reports provide direct evidence of how Guides frame written feedback for parents.

## Out

- **Parent reactions, trust, satisfaction, or understanding** — excluded because no parent-response data was available.
- **Handling parent disagreement** — excluded for the same reason.
- **Follow-up calls or two-way conversations** — excluded because no Guide-parent conversation records were available.
- **Whether parents acted on the feedback** — excluded for lack of outcome data.
- **General comment structure** — already covered under 8.1.

## Ambiguous

- The node title suggests two-way feedback, but the available evidence is one-way, parent-facing writing. The node was narrowed to written parent-facing feedback.
- Some contextual explanations were accurate but risked sounding like excuses. Context counted as positive only when followed by a Guide-owned action.
- Some negative wording was technically based on behavior but still inferred student intent.

# Node 8.3 — Progress Communication

## In

- **BL-064:** Communicate the student's trajectory through an earlier state, change or intervention, and current direction.
- **BL-065:** End with a measurable checkpoint that includes an action, measure, and timeframe.
- **BL-100:** Anchor goal meetings to the parents' stack-ranked pillars.

These were included because they are distinct: trajectory explains progress already observed, while a checkpoint defines how future progress will be evaluated.

## Out

- **Static descriptions of current performance** — static status belongs under comment content rather than progress communication.
- **Generic claims such as "making progress" without a comparison point** — excluded.
- **Future plans without a measurable target or review point** — excluded.
- **Multi-session longitudinal patterns** — excluded because most reports covered only Session 1.

## Ambiguous

- Some comments described recent improvement without giving an exact baseline.
- Some plans included a target but no monitoring cadence.
- Some comments explained data anomalies without clearly showing a trajectory.
- Evidence was included only when movement over time or a verifiable future checkpoint was explicit. Partial examples were treated as anti-patterns or left out.
